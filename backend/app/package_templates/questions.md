# Questions for the project owners

When a task needs a decision nobody made, or the code or a document contradicts a spec, write the question here
and stop that task. Bring this file back to itos: the decision is recorded there and the specs are updated.

## Template

### Q<n>: <the decision, as a question>

- **Spec and task:** 01 T2
- **Why it blocks:** what cannot be built without the answer
- **What was found:** the code, document or spec lines that disagree, if any
- **Options seen:** the choices you noticed (no recommendation needed)
- **Status:** open
